# Danchi reference photos

These are 39 freely licensed photos from Wikimedia Commons of 1960s–90s Japanese danchi and similar
mid-rise concrete housing. Two of them are non-Japanese rust-streak close-ups. They are `--ref` targets for
`.claude/skills/procedural-assets/scripts/frame_critique.py` (`reference_match`, `palette`).
The research behind them is in `docs/redesign/research/rR-reference-photos.md`.

The images are **not in git**. To download them:

```
python docs/redesign/evidence/refs/fetch_refs.py            # into docs/redesign/evidence/refs/img/ (git-ignored)
python docs/redesign/evidence/refs/fetch_refs.py OUT_DIR
```

`manifest.json` lists each photo's file name, view category, Commons page, download URL, author,
licence and a short description. The files are the 1920 px standard thumbnails that Commons serves
(Commons no longer renders arbitrary widths such as 1600 px). Photos whose original is smaller are
served at their original size.

## Use and attribution

Each photo stays under its own licence; none of them is ours. CC BY and CC BY-SA require credit
to the author, a link to the licence, and a note of any changes. If a photo is redistributed or
published, credit it as in the table below. If a modified version is shared, CC BY-SA requires that it
keep the same licence. Only measurements are used here; the images are not modified, and none is
redistributed in this repository. CC0 and public-domain photos need no credit, but they are listed too.

Photos by Wikimedia Commons contributors. Author names are as given on each file page; for
Flickr imports, the author is the Flickr account.
